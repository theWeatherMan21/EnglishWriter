# 两分钟手动核对单（爹地专用）

> 目的：补上**只有真人能干**的两条证据。全过程两分钟，不装东西、不改设置。
> 我这边的自动化已经把能造的造完了；剩下这两条我造不出来，也不许造（合成键击冒充键盘 = 造假）。

## 准备（10 秒）

确认菜单栏有铅笔图标（英文写作助手在跑）。没有就从「应用程序 → Selfmade」里打开一次。

## 核对 1：原生 App 里真敲英文（约 60 秒）

1. 打开 **TextEdit**，新建空白文档
2. 打这一句（照抄，故意留错）：

```
There is many reasons why we should sent the booking confirmation immediatly.
```

3. 停手等 1 秒，看这三处：

- [ ] `many reasons` 底下有**红色直线**（语法）
- [ ] `sent` 底下有**红色直线**
- [ ] `immediatly` 底下是**红色波浪线**（拼写）

4. 鼠标移到 `immediatly` 上 → 出现卡片，点「接受」
- [ ] 文档里真的变成 `immediately`

5. 按 `⇧⌘Z`
- [ ] 变回 `immediatly`

**任一项不符**：告诉我是哪一项 + 截图，我按图形/几何/引擎三层查。

## 核对 2：Mail 里真敲英文（约 60 秒）

1. 打开 **Mail** → 新建邮件（不填收件人、不发送）
2. 正文里打同一句
3. 停手等 1 秒：

- [ ] 三处下划线出现（位置压在对应词下方）

> 只读：我只拿「有没有画出线」这一个事实，不读你的邮件内容，不存正文，不发送任何东西。

## 核对 3（可选，10 秒）：中文零干扰

在 TextEdit 里打一句中文：

```
这是一句中文，不应该被检查。
```

- [ ] 没有任何下划线、没有卡片

---

## 回给我就三句话

```
1 原生划线：对 / 错（哪处）
2 Mail划线：对 / 错
3 卡片接受+撤销：对 / 错
```

这三句一到，我就把 parity 最后两格从「待真人复核」改成 R1，项目就能对外说「跟 Grammarly 一样」了。
