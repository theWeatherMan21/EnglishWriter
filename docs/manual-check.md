# 两分钟手动核对单（爹地专用）

> 只补**只有真人能干**的四条证据。两分钟，不装东西、不改设置。
> 合成键击冒充键盘 = 造假，这一步我不会代做。

## 准备

菜单栏有铅笔图标 = App 在跑。没有就从「应用程序 → Selfmade」打开一次。

## 1. 原生 App：真敲英文（约 40 秒）

1. 打开 **TextEdit**（或 **Mail** 新建邮件，不填收件人不发送）
2. 打这一句（照抄，故意留错）：

```
There is many reasons why we should sent the booking confirmation immediatly.
```

3. 停手 1 秒，看三处：
- [ ] `many reasons` 下有**红线**
- [ ] `sent` 下有**红线**
- [ ] `immediatly` 下是**波浪线**
- [ ] 输入框右下角出现**浮动球**（绿点=无问题 / 环里有数字=有 N 条）

4. 鼠标移到 `immediatly` → 卡片出现 → 点「接受」→ 文字变成 `immediately` → 按 `⇧⌘Z` 还原

## 2. 浮动球（10 秒）

- [ ] 左键点球 → 跳到下一条建议
- [ ] 右键点球 → 有「在此 App 关闭」，点了之后确实不再提示

## 3. 改写/语气（20 秒，需要模型接口已配）

1. 选中上面整句 → 菜单栏 → **改写选中段落…**
2. 等 5–10 秒，弹出候选（更简洁 / 更正式 / 更清晰）
3. 点一个 → 文字被改 → `⇧⌘Z` 能整体还原
4. 卡片里也有「改写 / 语气」两个按钮，同样点一次试试

## 4. 中文零干扰（5 秒）

打一句中文 `这是一句中文，不应该被检查。`
- [ ] 没有下划线、浮动球是绿的

---

## 已知边界（不是 bug，别白试）

| 宿主 | 状态 |
|---|---|
| TextEdit / Notes / 浏览器网页 | 支持（原生 + WebKit） |
| **Mail 阅读视图** | 链路已证（后台取文本 + 矩形对得上，R2）；**写邮件视图待验** |
| Chrome / Edge | 用扩展（`extension/`），不是在 App 里 |
| **WPS / Word** | **不支持**：自绘控件，AX 读不到文字。要用得走加载项（另开一条线） |
| 单行 input（搜索框那种） | 不支持（Grammarly 也不做） |
| 屏锁 / 被动模式 | 刻意零上屏 |

## 回我就四句话

```
1 原生划线+浮动球：对 / 错
2 卡片接受+撤销：对 / 错
3 改写候选：对 / 错
4 中文没干扰：对 / 错
```
